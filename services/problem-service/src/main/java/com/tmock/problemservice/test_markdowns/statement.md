# Two Sum

## Задача
Дан массив целых чисел `nums` и число `target`.  
Нужно найти **два индекса** массива, такие что сумма элементов по этим индексам равна `target`.

- Каждое входное значение используется не более одного раза.
- Гарантируется существование ровно одного решения.
- Индексы можно вернуть в любом порядке.

---

## Примеры

### Пример 1
**Ввод:**  
`nums = [2, 7, 11, 15], target = 9`  
**Вывод:**  
`[0, 1]`  
**Объяснение:**  
`nums[0] + nums[1] = 2 + 7 = 9`

---

### Пример 2
**Ввод:**  
`nums = [3, 2, 4], target = 6`  
**Вывод:**  
`[1, 2]`

---

### Пример 3
**Ввод:**  
`nums = [3, 3], target = 6`  
**Вывод:**  
`[0, 1]`

---

## Ограничения
- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`

---

## Дополнительно
Придумайте решение быстрее, чем `O(n^2)`.
